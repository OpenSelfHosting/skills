# Changelog

All notable user-facing changes to this project are documented here.

## 1.0.0 — Initial public collection

- Added 14 focused skills for onboarding, debugging, review, testing, CI diagnosis, security, dependencies, database migrations, API contracts, docs, pull request preparation, release readiness, skill authoring, and source-backed research.
- Added authoring, testing/evaluation, Arabic quick-start, and release documentation.
- Added a dependency-free structural validator, unit tests, per-skill evaluation cases, and GitHub Actions CI.
- Established MIT licensing and contribution/security policies.

> Initial package baseline. Host-agent behavioral evaluations have not been run by this build process; see `docs/testing-and-evaluation.md`.
