# Support

- **How-to questions:** open a GitHub Discussion if Discussions are enabled for this repository, or start an issue using the question template if one is provided.
- **Bug reports:** open an issue with the affected skill, host agent/version, reproduction prompt (redacted), expected behavior, actual behavior, and relevant evaluation case.
- **New skill ideas:** use the skill request issue template and describe the recurring problem, target users, and what a successful output looks like.
- **Security reports:** follow [SECURITY.md](SECURITY.md); do not use public issues for sensitive reports.

This is a community project. No response time or compatibility guarantee is implied. When requesting help, include only information you are allowed to share.
